# 二胡调音器

一个简洁易用的网页版二胡调音器，专为老年人设计。

## 功能

- 🎯 圆形指针仪表盘，实时显示音准
- 🔢 大字显示频率（Hz）
- 🎻 自动识别内弦（D ≈ 293.7Hz）/ 外弦（A ≈ 440Hz）
- 📊 音分偏差显示（±50¢）
- 🔊 参考音播放按钮
- 📱 适配 iPhone，支持添加到主屏幕

## 使用方法

1. 用系统浏览器（Safari/Chrome）打开 `index.html`
2. 点击「开始调音」，允许麦克风权限
3. 拉琴，观察指针位置
4. 指针居中 = 音准

## 部署

将 `index.html` 上传到任意 HTTPS 静态托管服务即可（GitHub Pages / Vercel / 腾讯云等）。
