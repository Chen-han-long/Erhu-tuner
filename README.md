二胡调音器
基于 Web Audio API 的浏览器二胡调音器，面向手机与老人使用场景：界面保持简单，只需点“开始调音”后拉弦看指针。
当前版本改进
低延迟实时音高检测：使用针对二胡 D4 / A4 范围优化的 YIN 检测
更快判断“偏高 / 偏低 / 音准很好”，中心附近加入迟滞，减少文字闪烁
约 21ms 音频分析窗口，检测约 42 次/秒
自适应频率平滑：变化大时快速跟随，变化小时抑制抖动
机械指针：使用基于真实时间的弹簧 + 阻尼模型，不受 60Hz / 120Hz 屏幕影响
指针改为尖针、尾锤、中心轴帽，更接近真实仪表
表盘静态层缓存，动画时只重画指针，减少手机 GPU/CPU 压力
修复音高检测与指针动画共用 requestAnimationFrame ID 的问题
停止调音时正确关闭麦克风轨道
PWA 离线支持，并改进更新策略，部署新版后不容易长期卡在旧缓存
标准音
内弦 D4 ≈ 293.7Hz
外弦 A4 = 440Hz
部署
上传到任意静态托管服务（GitHub Pages / Vercel / 腾讯云 COS 等），必须使用 HTTPS。
GitHub Pages 更新文件后，重新打开页面即可获取新版；如果浏览器仍保留旧页面，可完全关闭后重新打开一次。
使用
浏览器打开 → 允许麦克风 → 拉琴看指针。
指针偏左 / 蓝色提示：偏低，请拧紧
指针在中间 / 绿色提示：音准很好
指针偏右 / 红色提示：偏高，请拧松
⚠️ 微信内置浏览器通常无法正常使用麦克风，请跳转到 Safari / Chrome / 系统浏览器。
